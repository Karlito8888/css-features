A colour font made for this page: each shape has three colour layers and the font carries three palettes, 0 by default, 1 for light backgrounds and 2 for dark ones. normal uses palette 0, light and dark the palette made for that background, --custom a name defined with @font-palette-values. Chrome 101+, Firefox 107+, Safari 15.4+; palette-mix() Chrome 121+ only.
