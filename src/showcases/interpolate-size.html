This browser does not support interpolate-size, so both panels jump open.

Open both panels. Same CSS, same transition, one property apart.

numeric-only (default)

The height goes from 0 to auto. Auto is a keyword, not a number, so the browser has nothing to interpolate and the panel snaps.

allow-keywords

The height goes from 0 to auto. With the keyword allowed, the browser computes the real content height and animates to it.
